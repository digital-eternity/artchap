# Контекст проекта
**Название:** Сайт-визитка «Артём Чапковский — гитара, ансамбль, оркестр»
**Тип продукта:** Легковесный статический сайт (HTML/CSS/минимум JS).
**Цель:** Привлечение учеников на частные уроки (офлайн в СПб и онлайн) и набор участников в ансамбль/оркестр. Второстепенная цель — просветительская деятельность.
**Целевая аудитория:**
1. Взрослые-новички (хотят играть для себя, боятся сложностей).
2. Дети и их родители (ищут надежного педагога с опытом).
3. Любители среднего уровня (хотят играть в коллективе, нужен ансамбль/оркестр).
**Ключевая маркетинговая идея:** Преподаватель — практикующий музыкант, который учит играть так, чтобы ученик мог играть с другими. Сайт транслирует дружелюбие, профессионализм и отсутствие «академической духоты». Визуальный ряд подтверждает экспертность и открытость.
**Основные каналы связи:** Только мессенджеры (Telegram — основной, VK — резервный).
**Tone of Voice:** Уверенный, живой, современный, дружелюбный, без канцеляризмов.
**Визуальные материалы:** Предоставлены 4 профессиональных фото (крупный план, портрет в рубашке, официальный с бабочкой, игра в оркестре).
